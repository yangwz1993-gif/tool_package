# 内容、布局和交互验收

## 独立预期文件

从原始流程提取预期，不从编译结果自证正确。最小格式：

```json
{
  "default_view": "index",
  "elements": ["draft", "review", "done"],
  "visible_nodes": ["draft", "review", "done"],
  "relations": [["draft", "review", "提交"], ["review", "draft", "退回"], ["review", "done", "通过"]],
  "content": {"draft": {"title": "填写申请", "description": "完整说明"}},
  "canvas": [1360, 750],
  "minimum_font_px": 12
}
```

`elements` 和 `visible_nodes` 包括需要展示的真实容器。关系逐条列出，允许重复，必须保留方向、条件及数量。`content` 可核对 `title`、`description`、完整 `metadata`。不要求修改用户原文。

视图 `group` 是显示边界，不计为业务步骤。在 `view_groups` 中分别声明标题和成员，例如 `"view_groups": {"01 · 申请":["draft","review"], "02 · 完成":["done"]}`。脚本单独核对业务节点和分区，不能用多一个分区抵消少一个步骤。

当用户接受大画布时，可设置 `"reading": {"mode":"pan-zoom", "scale":0.9}`。字号标准仍为至少 12px，按 90% 阅读缩放估算，同时报告缩略总览字号；默认 `fit` 模式继续按窗口容纳全图估算。单视图项目另加 `"viewer":"reader"` 可将此比例用于初始阅读，并显示阶段导航。脚本核对阅读入口的模型与原始导出相同、初始比例配置相同；实际显示效果仍须浏览器验证。

## 脚本检查

- 语法和引用有效；失败保留日志和非零退出码。
- 节点、方向、条件及指定内容符合预期；默认视图展示所有预期节点和模型关系。
- 节点无非包含关系的重叠，采样连线没有穿过无关节点、独立连线交叉、边标签压框、双向边近乎重合。
- HTML/CSS 的静态依赖及字面量动态 import 已内嵌。
- draw.io、SVG 的节点和边数量与视图一致。
- 使用原生布局快照时检查漂移、方向和声明的分区对齐；检查阅读器使用的是已解析的手动布局，不能仍定位到自动布局坐标。
- 按声明的阅读模式估算最小静态字体，保留总览的字号数据。大画布不要求所有文字在缩略总览中可读。估算不能替代实际窗口检查。

几何检查有局限：曲线采样可能漏报，交叉检查不涵盖共端点或共线重合，静态字体不等于浏览器字体。图本身有必要交叉时，保留关系，说明限制并继续调整；不要把报告改成全绿。

## Agent 实际操作

在获准的浏览器里做以下检查，记录窗口大小、截图/可见状态和结果：

1. 打开最终 `flow.html`。默认视图包含全部步骤，阶段分区可见；大画布允许超出窗口。检查初始画面及阅读缩放下的标题、条件、阶段顺序和连线；重点确认标签深浅、中文换行和箭头遮挡，不能用 PNG 代替。若默认总览过小，记录实际体验问题。
2. 打开普通步骤、判断、返工节点的详情。核对完整名称、说明、metadata 和特殊字符。
3. 放大、缩小、平移、适应画布或复位后检查内容仍可见；关闭详情能回到图。
   阅读入口另测：从第一阶段开始、七个阶段定位、从总览返回阅读、普通滚轮平移与修饰键缩放。
4. 刷新后可恢复首页；多视图项目测试切换和返回。
5. 在授权环境中断开网络后重新打开单 HTML，验证文字、图、详情、缩放仍工作。若工具没有断网或本地文件能力，记录“未实测”，不伪造通过。

将浏览器实测另存为 `browser-verification.json`，至少含 `html_sha256`（对应脚本报告）、时间、浏览器、窗口大小、每项结果和证据位置。产物变更后，旧浏览器报告不能自动继承。

浏览器访问被拒绝时，不换端口或工具绕过。继续做独立检查；最后明确交互和离线验收待补。用户无需替 agent 跑技术测试。
