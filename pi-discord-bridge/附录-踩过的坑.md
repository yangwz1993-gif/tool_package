# 附录：踩过的坑

搭建过程里踩到的坑。每条给「现象 / 根因 / 解法」，比操作步骤更值得读，因为它们大多**不报错**。

## pgrep 匹配不到明明存在的进程

**现象**：`pgrep -f "/opt/homebrew/bin/herdr server"` 返回 0，但 `ps` 里那个进程就在那儿。

**根因**：macOS 的 `pgrep -f` 对这条命令行的匹配就是失灵，原因未明。这让所有依赖「数进程」的脚本判断失真。

**解法**：herdr 的存活判断走 `herdr status`（输出里有 `status: running`），或者用 `ps` + `awk` 精确取 pid：

    ps -axo pid=,command= | awk '/\/opt\/homebrew\/bin\/herdr server/ {print $1}'

## launchctl submit 退出码 126

**现象**：`launchctl submit -l label -- /bin/sh -c "sleep 40; exec /bin/bash '<中文路径>'"` 之后任务登记成功，但日志只有一行、脚本一步没跑，退出码 126。

**解法**：两件事一起做。

- 脚本复制到纯 ASCII 路径再交给 launchd
- 把「等回复发出去」的延迟**挪进脚本内部**，而不是放在启动器的 `sleep` 里。这样脚本会先写下「启动」日志再动手，跑没跑起来当场可验证

另外，纯 `nohup` 不足以让脚本脱离 herdr 的进程树，要用 launchd 托管才可靠。

## 完全磁盘访问给了但不生效

**现象**：系统设置里加了授权，也重启了进程，`sqlite3 TCC.db` 仍然 `authorization denied`。

**根因**：执行体是 Homebrew 装的 **adhoc 签名**二进制（`codesign -dv` 显示 `Signature=adhoc`、`TeamIdentifier=not set`）。TCC 需要稳定可验证的代码身份，adhoc 签名拿不到持久授权，条目在列表里但不实际生效。

**附带问题**：`/opt/homebrew/bin/herdr` 是符号链接，真身在 `Cellar/herdr/<版本>/bin/herdr`。授权对象指错路径同样不生效，而且 brew 升级换版本后授权会失效。

## 模型静默切到另一个供应商

见 [03-房间与模型](03-房间与模型.md) 的「坑一」。补一条现象特征：**从聊天记录里看不出切错了**，因为两个模型的字符串显示一样，只有状态栏括号里的 provider 名能区分。

## 改了配置却迟迟不生效

见 [03-房间与模型](03-房间与模型.md) 的「坑二」。模型表是进程启动时的快照，新增凭证后必须 `/reload`。

## 自己 reload 自己会被拒

**现象**：`herdr pane run <自己的 pane> "/reload"` 返回「等当前响应结束」。

**根因**：pi 在 streaming 时硬拒 reload，这是设计如此。

**解法**：延迟执行，排到回合之后。

## Discord 手机端不渲染折叠

`||剧透||` 在手机端完全不可用，点了也不展开。所以分层只能靠「视觉上可跳过」，不能靠「点击展开」。

引用块、小字（`-#`）、代码块三种可用。其中代码块拿来装排版会又挤又乱，只留给真正的代码和原始日志。

## 折叠标记会被表格正则吃掉

**现象**：`||内容||` 发出去变成了 `• **** — 内容`。

**根因**：`||` 首尾都是 `|`，撞上了 markdown 表格行的识别规则 `/^\s*\|.*\|\s*$/`，被当成表格拆成了要点。

**解法**：识别表格行之前先排除首尾都是 `||` 的行。

排查这类问题有个通用手法：**把实际发出去的内容从 API 读回来看原文**，一眼就能区分是「客户端不渲染」还是「发送前就被改坏了」。

## 不要 grep 大目录

`grep` 递归扫 `~/.pi/agent`、`~/Desktop` 这类目录会挂死（实测 23 分钟不动）。要找东西用 `find` 精确定位，或者把范围锁到具体文件。

## `herdr tab get` 不返回 pane

它只给 tab 元数据。要 pane 就用 `herdr pane list`。按「编号最小的 pane」去猜某个 agent 的位置会猜错，必须按 `pane_id` 或 `agent_session.value` 精确匹配。

## 临时目录不是 `/tmp`

Node 的 `os.tmpdir()` 在 macOS 上是 `/var/folders/.../T/`，不是 `/tmp`。查缓存文件时按 `/tmp` 找会误判成「不存在」。

## 没定价的模型不是免费

自定义模型 `cost` 填 0 只代表**没定价**，不代表免费。看到 `$0.00` 先确认是真免费还是没配价。

## DeepSeek 有峰谷价

谷时价格是高峰的一半。pi 不区分峰谷一律按高峰算，所以谷时开销会被高估一倍。

## reload 时第三方扩展可能抛异常

`/reload` 时第三方扩展如果自身有 bug，会抛异常，但 reload 本身仍然完成，只是那个扩展可能降级。遇到「reload 后某功能没了」先看扩展日志。

## herdr server 没有开机自启

它不是 launchd 托管的，机器重启后要手动拉起，否则 Discord 那边会全部失联。想长期挂着建议做一个 LaunchAgent。
